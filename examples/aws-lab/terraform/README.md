# terraform/ — Legacy Generation 1/2 Lab

This directory contains the original Terraform configuration for the Generation 1 (server/agent) and Generation 2 (eBPF observer) AWS labs.

It was used to validate Gates A through K.1 (server, physarum-agent, physarum-ebpf-observer, physarum-packet-observer).

**Current labs use `terraform-pf1/` and `terraform-pf2/`** (physarum-maze autonomous propagation — Gates PF-1 and PF-2).

This directory is kept for historical reference. Do not use it for new lab runs.
