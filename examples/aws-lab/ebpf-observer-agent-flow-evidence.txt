  NOTE on comm=swapper/0:
  The tracepoint/sock/inet_sock_set_state fires in softirq (network stack)
  context. task_struct->comm at that moment reflects the kernel idle process
  (swapper/N), not the physarum-agent thread that initiated the connection.
  This is expected behavior for async I/O. The 5-tuple uniquely identifies
  the physarum-agent → agent-c probe flow:
    source_ip=10.50.20.10 (agent-b)  destination_ip=10.50.30.10 (agent-c)
    destination_port=9002             direction=outbound
    event=connect_established
  Correct process attribution via BPF socket-ownership map is deferred to
  a future gate (Gate K scope).
